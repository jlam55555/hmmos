Attempt to evict items until size_hint items are remaining.

This interface doesn't allow you to choose which elements to evict (that would require revoking all active leases).

Parameters

Lookup an item in the cache. If it doesn't exist, atomically fetch the contents and insert it into the map.

"Atomic" means that if one thread has started fetching/evicting an element, any later accesses to get() will wait for the first to complete.

Parameters
insert_if_missingif false, returns an empty Lease if the item is not present in the cache. This should only be used for O_DIRECT I/O.
